One line, under 200 characters, in which a dog explains why the homework
got eaten — for the [make.fun bounty](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c).
A model judge reads entries two at a time and keeps the funnier one.

`main.ts` builds a candidate pool of excuses, scores each one against the
judge's own published criteria (dog voice first, then the laugh, then
sounding like a real dog, self-contained, fresh), and writes the winner to
`/output/entry.txt`.

The winning line:

> It knew the answers and wouldn't share. So I ate the witness.

Run locally with `node main.ts` (Node 22+, no dependencies).
